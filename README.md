# TestGunGame

Windows에서 Wii 리모컨과 일반 USB 센서바를 사용하여 Three.js 기반 1인용 레일 슈팅 1스테이지를 만드는 기술 테스트 프로젝트다.

- [구현 계획: 총 연결부터 게임 제작과 실물 검증까지](구현-계획-1.md)
- [T07·T08 게임 화면과 플레이 명세: 예상도와 한 판의 흐름](게임-화면과-플레이-명세-2.md)

시험 모드는 자동 이동하는 레일 슈팅 1스테이지와, Wii 십자 버튼으로 이동하며 조준·사격하는 자유 이동 시험장으로 나눈다. 자유 이동은 전방 시선 고정·좌우 옆걸음 방식이며 눈차크가 필요하지 않다.

현재 상태: 레일 슈팅 1스테이지(A·B·C, 적 15명)와 시작·보정·일시정지·결과 화면을 구현했고 마우스로 완주를 확인했다. Wii 리모컨은 별도 프로그램 없이 브라우저(WebHID)가 직접 연결하도록 구현했으며, 실제 리모컨 연결 확인은 남아 있다. 자유 이동 시험장(T13)은 아직 없다.

## 실행

배포 형태는 Windows 게임 실행 파일(`host/`, C# .NET Framework 4.8 + WebView2)이다. 리모컨 블루투스 등록까지 게임 안에서 처리한다. 웹 브라우저 버전은 개발·마우스 플레이용이다.

빌드에는 Node.js 24 이상과 .NET SDK가 필요하다. 사용자 PC에는 Windows 10/11 기본 구성 외에 설치할 것이 없다.

```powershell
npm run app:build  # 웹 빌드 + 실행 파일 빌드 → host\bin\Release\net48\ (TestGunGame.exe + game\)
npm run app        # 빌드한 게임 실행
npm run app:dev    # 개발 서버(npm run dev)를 띄운 상태에서 실행 파일로 열기(F12 개발자 도구)
```

```powershell
npm install
npm run dev        # http://localhost:25001 (Chrome 또는 Edge로 연다)
npm test           # 규칙·프로토콜·보정 자동 시험
npm run build      # dist/ 생성
npm run preview    # http://localhost:25002 에서 빌드 결과 확인
```

`F3`로 입력 진단 화면을 연다(조준 좌표, 프레임 시간, 리모컨 상태·배터리·IR 점·감도).

## Wii 리모컨 연결

별도 입력 프로그램이나 드라이버는 설치하지 않는다. **게임 시작**을 누르면 실제 게임처럼 컨트롤러 설정이 단계별로 나오고, 각 단계는 장치를 감지하면 자동으로 넘어간다.

1. **조작 방식 선택** — Wii 총 또는 마우스.
2. **리모컨 연결** — 화면에 "빨간 SYNC 버튼을 누르세요"가 나오면 누르기만 한다. 게임이 블루투스 등록과 연결을 직접 하며, 흔한 방식부터 될 때까지 바꿔 가며 시도한다. 전에 연결한 리모컨은 아무 버튼이나 누르면 된다. (웹 브라우저 버전에서는 Windows Bluetooth 등록 안내와 장치 선택 창이 대신 나온다.)
3. **센서바 확인** — 총을 화면 가운데로 향하면 IR 점 두 개를 감지해 통과한다. 잡히지 않으면 원인 안내가 나온다.
4. **버튼 확인**(처음 한 번) — 방아쇠, 엄폐 버튼, + 버튼을 차례로 누르면 실제로 눌린 버튼이 그 기능으로 저장된다.
5. **조준 보정** — 5지점을 겨냥해 방아쇠. 화면 조건이 바뀌면 다시 한다.

다음부터는 연결·센서바 확인만 자동으로 거치고 바로 게임이 시작된다. 시작 화면의 **컨트롤러 설정**으로 처음부터 다시 할 수 있다. 개발 서버에서는 각 단계 결과와 리모컨 상태가 `logs/hw-check.log`에 기록된다.

| 동작 | Wii 총 | 마우스·키보드 |
| --- | --- | --- |
| 조준 | 총을 화면으로 향한다 | 마우스 이동 |
| 발사 | 방아쇠(B) | 왼쪽 버튼 |
| 엄폐·재장전 | 설정에서 고른 버튼(보통 A) 유지, 0.8초 유지 시 장전 | Space 또는 오른쪽 버튼 유지 |
| 일시정지 | + / − / HOME | Esc 또는 P |
| 메뉴 선택 | 버튼을 겨냥하고 방아쇠 | 클릭 |

**문제 해결:** 연결 화면에 오류가 나오면 Dolphin 등 리모컨을 쓰는 다른 프로그램을 종료하고, 리모컨 전원을 껐다 켠 뒤 다시 찾는다. 진단 화면(F3)의 IR 점이 0개면 센서바 USB 전원과 방향을 확인한다.

## 이전 시도(Touchmote) 정리

T03에서 시험한 Touchmote는 보안·배포 문제로 쓰지 않는다([구현 계획 18절](구현-계획-1.md)). 이 PC에 남은 구성은 다음 순서로 정리한다.

```powershell
certutil -user -delkey 7409b7d5-8e75-4b80-ae90-9c11e157f164                      # 남은 서명용 개인 키 삭제
Remove-Item Cert:\CurrentUser\Root\CEC32DDA81D6049B674A7B9BC3EB12287B5B1448      # 자체 서명 루트 인증서 삭제(확인 창)
```

그다음 **설정 → 앱**에서 Touchmote를 제거한다.

## 저가 Wii 총 구성 참고

게임용 입력장치에 **15만~20만원을 쓰는 것은 부담이 크다.** 저가 대안으로 Wii 리모컨을 활용하는 구성을 검토한다.

다만 PS1용 건과 지금의 PC용 건은 조준을 인식하는 방식에 차이가 있다. **PS1의 건콘 같은 제품은 브라운관 화면의 주사 타이밍을 이용하기 때문에, 일반 USB 변환기를 붙여도 LCD·OLED 모니터에서 조준이 되지 않는다.** 현대 화면에서는 별도의 위치 추적 장치가 필요하다. [관련 제조사 설명](https://www.ultimarc.com/Aimtrak%20PS2%20guide%20v_1.pdf)

저렴하게 접근한다면 **중고 Wii 리모컨에 총 모양 케이스를 끼우는 구성**부터 검토하는 것이 적절하다. 이 프로젝트에서는 이미 보유한 Wii 리모컨과 건을 우선 활용한다.

| 구성 | 역할 | 구매 경로 |
| --- | --- | --- |
| **Wii 리모컨** | 적외선 카메라와 버튼이 들어 있는 실제 컨트롤러다 | 국내 중고 제품과 [알리 검색](https://www.aliexpress.com/w/wholesale-wii-remote-controller.html)을 비교한다 |
| **Wii용 총 케이스** | 리모컨을 총처럼 잡고 방아쇠를 누르게 한다 | [알리 검색](https://www.aliexpress.com/w/wholesale-wii-zapper-gun.html) |
| **PC 연결·적외선 기준 장치** | 리모컨을 PC에 연결하고 조준 기준점을 제공한다 | 아래 두 방법 중 선택한다 |

PC 연결 방법은 다음과 같다.

- **비용 우선:** Wii 리모컨 + 일반 USB 센서바 + PC 블루투스를 사용한다. PC에서 좌표를 읽어 게임에 연결하는 소프트웨어 작업과 호환성 확인이 필요하다. [USB 센서바 검색](https://www.aliexpress.com/w/wholesale-wii-usb-sensor-bar.html)
- **설정 편의 우선:** 일반 센서바 대신 **Mayflash DolphinBar W010**을 사용한다. 제조사에서 Windows 연결과 마우스 모드를 지원한다고 명시한다. [제조사 설명](https://www.mayflash.com/product/W010.html) · [알리 검색](https://www.aliexpress.com/w/wholesale-mayflash-dolphinbar.html)

**알리에서 몇천원~1만원대로 보이는 ‘Wii Gun’은 컨트롤러 없이 플라스틱 케이스만 파는 경우가 있으므로 구성품을 확인해야 한다.** 일반 USB 센서바 역시 블루투스 수신기가 포함된 DolphinBar와는 다른 제품이다. 일반 USB 센서바는 적외선 LED에 전원을 공급하며, 리모컨 입력은 PC 블루투스를 통해 전달된다.

처음에는 **정품 Wii 리모컨으로 총 케이스 없이 PC 연결부터 검증하는 것**을 추천한다. 리모컨이 없으면 중고 제품을 저렴하게 확보하는 방법을 검토한다. 직접 게임을 만들 수 있으므로 좌표 보정과 조준점 표시를 게임에 넣는 방향도 가능하다. 다만 가늠쇠로 겨눈 곳에 정확히 맞는지는 실제 거리와 자세에서 확인해야 한다.

**기존 조사에서는 ‘1만원대 완제품·현대 모니터 직접 조준·PC 연결’을 모두 충족하는 제품을 확인하지 못했다.** 위 링크는 저가 구성을 위한 검색 경로이며, 현재 판매가와 배송비는 확인되지 않았다.
